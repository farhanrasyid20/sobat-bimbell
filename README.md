# Proyek Sobat Bimbel Semester 1

- Kode Tim: IF-1MA-04
- Judul: Sistem Informasi Sobat Bimbel

## Deskripsi Permasalahan
Sobat Bimbel merupakan aplikasi berbasis web yang dikembangkan untuk membantu pengelolaan operasional bimbingan belajar secara digital. Sistem ini dirancang untuk memudahkan admin, guru, dan siswa dalam melakukan proses akademik seperti pengelolaan data siswa, data guru, jadwal belajar, absensi, serta pengelolaan nilai secara lebih terstruktur dan efisien.

Pada pengembangan semester 1, sistem difokuskan pada pembuatan fitur dasar seperti autentikasi pengguna, manajemen data siswa dan guru, pengelolaan mata pelajaran, serta sistem penilaian sederhana. Aplikasi ini dibuat untuk meningkatkan efisiensi pengelolaan data dibandingkan proses manual yang sebelumnya digunakan.
